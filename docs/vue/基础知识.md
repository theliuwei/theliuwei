# Vue 基础知识

Vue.js 是一款流行的渐进式 JavaScript 框架，专注于构建用户界面。它易于上手，适合快速开发单页应用（SPA）。

## 1. 安装与引入

- 通过 CDN：
```html
<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
```
- 通过 npm：
```bash
npm install vue
```

## 2. 创建 Vue 应用

```html
<div id="app">{{ message }}</div>
<script>
const { createApp } = Vue
createApp({
  data() {
    return { message: 'Hello Vue!' }
  }
}).mount('#app')
</script>
```

## 3. 核心概念

- **数据绑定**：`{{ message }}`
- **指令**：以 `v-` 开头的特殊属性，如 `v-if`、`v-for`、`v-bind`、`v-model`。
- **事件处理**：`v-on:click` 或简写 `@click`。

## 4. 常用指令

- `v-if`：条件渲染
- `v-for`：列表渲染
- `v-bind`：绑定属性，简写为 `:`
- `v-model`：双向数据绑定
- `v-on`：事件监听，简写为 `@`

## 5. 组件

组件是 Vue 的核心思想之一，用于复用 UI 结构和逻辑。

```js
// 定义组件
const MyComponent = {
  template: '<div>自定义组件</div>'
}
// 注册并使用
createApp({
  components: { MyComponent }
}).mount('#app')
```

## 6. 生命周期

Vue 实例有一系列生命周期钩子：
- `created`：实例创建后
- `mounted`：挂载到 DOM 后
- `updated`：数据更新后
- `unmounted`：卸载后

```js
const app = createApp({
  mounted() {
    console.log('组件已挂载')
  }
})
```

## 7. 计算属性与侦听器

- **计算属性**：基于响应式依赖进行缓存
```js
computed: {
  reversedMessage() {
    return this.message.split('').reverse().join('')
  }
}
```
- **侦听器**：监听数据变化
```js
watch: {
  message(newVal, oldVal) {
    console.log('message 变了')
  }
}
```

## 8. 生态与工具

- Vue Router：前端路由管理
- Pinia/Vuex：状态管理
- Vue CLI/Vite：项目脚手架

## 9. 父子组件通信

### 父传子（Props）
父组件通过 `props` 向子组件传递数据：

```js
// 子组件
export default {
  props: ['title']
}
```
```html
<!-- 父组件 -->
<MyComponent title="Hello" />
```

### 子传父（emit）
子组件通过 `$emit` 触发事件，父组件监听：

```js
// 子组件
this.$emit('customEvent', value)
```
```html
<!-- 父组件 -->
<MyComponent @customEvent="onCustomEvent" />
```

## 10. 插槽（Slot）
插槽用于让父组件向子组件传递内容，实现内容分发：

```html
<!-- 子组件 -->
<slot></slot>

<!-- 父组件 -->
<MyComponent>
  <p>插槽内容</p>
</MyComponent>
```

具名插槽：
```html
<slot name="header"></slot>
<!-- 父组件 -->
<MyComponent>
  <template #header>
    <h1>标题</h1>
  </template>
</MyComponent>
```

## 11. 响应式原理简介
Vue 通过响应式系统追踪数据变化，实现视图自动更新。Vue3 使用 Proxy 实现更高效的响应式。

- 响应式数据：`reactive`、`ref`
- 依赖收集与触发更新

## 12. 常用开发工具和调试技巧
- **Vue Devtools**：浏览器插件，调试组件状态和事件。
- **热重载**：保存代码自动刷新页面。
- **错误提示**：关注控制台报错，快速定位问题。

## 13. Vue3 新特性简述
- **Composition API**：`setup`、`ref`、`reactive`、`computed`、`watch` 等组合式函数。
- **Fragment**：组件可返回多个根节点。
- **Teleport**：将内容渲染到 DOM 的其他位置。
- **更快的响应式系统**：基于 Proxy。
- **更好的 TypeScript 支持**。

## 14. 路由（Vue Router）基础用法

Vue Router 是 Vue 官方的前端路由管理库，用于实现单页应用的页面切换。

- 安装：
```bash
npm install vue-router
```
- 基本用法：
```js
import { createRouter, createWebHistory } from 'vue-router'
import Home from './views/Home.vue'
import About from './views/About.vue'

const routes = [
  { path: '/', component: Home },
  { path: '/about', component: About }
]

const router = createRouter({
  history: createWebHistory(),
  routes
})
```
- 在 Vue 应用中使用：
```js
import { createApp } from 'vue'
import App from './App.vue'
createApp(App).use(router).mount('#app')
```
- 路由跳转：
```html
<router-link to="/about">关于</router-link>
<router-view></router-view>
```

## 15. 状态管理（Pinia/Vuex）简介

### Pinia（推荐，Vue3 官方）
- 安装：
```bash
npm install pinia
```
- 基本用法：
```js
import { createPinia, defineStore } from 'pinia'
const pinia = createPinia()

const useMainStore = defineStore('main', {
  state: () => ({ count: 0 }),
  actions: {
    increment() { this.count++ }
  }
})
```
- 在 Vue 应用中使用：
```js
createApp(App).use(pinia)
```

### Vuex（Vue2/早期 Vue3 项目）
- 用法类似，推荐新项目使用 Pinia。

## 16. 表单处理与校验

- 使用 `v-model` 实现表单双向绑定：
```html
<input v-model="username" />
```
- 简单校验：
```html
<span v-if="!username">用户名不能为空</span>
```
- 复杂校验可用第三方库，如 [VeeValidate](https://vee-validate.logaretm.com/v4/)。

## 17. 异步请求与常用库

- 推荐使用 [axios](https://axios-http.com/) 进行 HTTP 请求：
```bash
npm install axios
```
- 基本用法：
```js
import axios from 'axios'
axios.get('/api/data').then(res => {
  console.log(res.data)
})
```
- 可结合 async/await 使用：
```js
const fetchData = async () => {
  const res = await axios.get('/api/data')
  console.log(res.data)
}
```

## 18. 项目结构与最佳实践

- 推荐结构：
```
src/
  components/   # 组件
  views/        # 页面
  store/        # 状态管理
  router/       # 路由
  assets/       # 静态资源
  App.vue       # 根组件
  main.js       # 入口文件
```
- 组件化开发，单一职责原则
- 合理拆分页面与组件，便于维护
- 使用 ESLint/Prettier 保持代码风格统一

## 19. 动画与过渡（Transition）

Vue 提供了内置的 `<transition>` 组件，用于为元素或组件的进入/离开添加动画：

```html
<transition name="fade">
  <p v-if="show">淡入淡出效果</p>
</transition>
```

配合 CSS：
```css
.fade-enter-active, .fade-leave-active {
  transition: opacity 0.5s;
}
.fade-enter-from, .fade-leave-to {
  opacity: 0;
}
```

还可以用 `<transition-group>` 实现列表动画。

## 20. 自定义指令

Vue 允许开发者注册自定义指令，扩展 DOM 行为：

```js
app.directive('focus', {
  mounted(el) {
    el.focus()
  }
})
```

使用：
```html
<input v-focus />
```

## 21. 插件机制

Vue 支持插件机制，可以扩展全局功能。

```js
const MyPlugin = {
  install(app, options) {
    // 添加全局方法、指令等
    app.config.globalProperties.$myMethod = () => {}
  }
}
createApp(App).use(MyPlugin)
```

常见插件：Vue Router、Pinia、第三方 UI 库等。

## 22. SSR（服务端渲染）简介

SSR（Server-Side Rendering）可以让 Vue 应用在服务器生成 HTML，提高首屏速度和 SEO。
- 代表方案：[Nuxt.js](https://nuxt.com/)
- 适合需要 SEO 和更好首屏体验的项目

## 23. 常见性能优化建议

- 合理拆分组件，避免组件过大
- 使用 `v-show` 替代 `v-if` 频繁切换的场景
- 使用异步组件和懒加载
- 使用 `key` 优化列表渲染
- 避免不必要的响应式数据
- 生产环境关闭开发者工具和日志

## 24. Composition API 进阶

- **setup() 函数**：组件逻辑的入口，所有 Composition API 都在这里使用。
- **ref 与 reactive 区别**：`ref` 适合基本类型，`reactive` 适合对象和数组。
- **toRefs/toRef**：将 reactive 对象的属性转为 ref，便于解构。
- **provide/inject**：实现祖孙组件间依赖注入。

```js
// provide/inject 示例
// 父组件
import { provide } from 'vue'
setup() {
  provide('theme', 'dark')
}
// 子组件
import { inject } from 'vue'
setup() {
  const theme = inject('theme')
}
```

## 25. Teleport 传送门

用于将子组件的 DOM 渲染到父组件 DOM 结构外的任意位置（如模态框、弹窗等）。

```html
<teleport to="body">
  <div class="modal">我是弹窗</div>
</teleport>
```

## 26. Suspense 异步组件加载

用于优雅地处理异步组件加载和等待状态。

```html
<Suspense>
  <template #default>
    <AsyncComponent />
  </template>
  <template #fallback>
    <div>加载中...</div>
  </template>
</Suspense>
```

## 27. `<script setup>` 语法糖

`<script setup>` 是 Vue3 推荐的单文件组件写法，语法更简洁。

```vue
<script setup>
import { ref } from 'vue'
const count = ref(0)
</script>

<template>
  <button @click="count++">{{ count }}</button>
</template>
```

## 28. defineProps 和 defineEmits

在 `<script setup>` 中声明 props 和 emits：

```vue
<script setup>
const props = defineProps(['title'])
const emit = defineEmits(['update'])
</script>
```

## 29. defineExpose

用于在 `<script setup>` 中向父组件暴露子组件方法或属性。

```vue
<script setup>
const doSomething = () => { /* ... */ }
defineExpose({ doSomething })
</script>
```

## 30. 类型推断与 TypeScript 支持

Vue3 对 TypeScript 支持非常好，推荐在项目中使用类型注解提升开发体验。

```ts
<script setup lang="ts">
import { ref } from 'vue'
const count = ref<number>(0)
</script>
```

## 31. 响应式陷阱与注意事项

- 解构 reactive 对象会失去响应性，推荐用 `toRefs`。
- 不要直接修改 props，应该通过事件通知父组件。

## 32. 组合式函数（Composables）

把可复用的逻辑抽成函数，推荐以 `useXxx` 命名。

```js
// useCounter.js
import { ref } from 'vue'
export function useCounter() {
  const count = ref(0)
  const inc = () => count.value++
  return { count, inc }
}
```
